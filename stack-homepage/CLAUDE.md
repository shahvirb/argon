# Homepage Dashboard

This project provides a highly customizable, Docker-based homepage dashboard for your home lab. It uses the [gethomepage](https://gethomepage.dev/) application to display services, bookmarks, and system information in a clean and organized way.

## Getting Started

The homepage is run as a Docker container, defined in the `docker-compose.yaml` file. To get started, you can run the following command:

```bash
docker-compose up -d
```

All configuration for the homepage is stored in the `homepage/` directory, which is mounted into the container.

## Configuration

The dashboard is configured through a set of YAML files located in the `homepage/` directory:

- `services.yaml.tpl`: This is the main file for defining the services that appear on the dashboard. You can group services, add widgets, and specify links and icons.
- `services.yaml`: Don't edit this file. It is generated by running `op-unpack.sh` as per the secrets management instructrions below.
- `settings.yaml`: This file controls the overall layout and appearance of the dashboard, including the theme, title, and how service groups are arranged.
- `bookmarks.yaml`: Use this file to add and manage bookmarks.
- `widgets.yaml`: This file is for global widget settings, such as search providers and resource monitoring.

**Note:** Changes to these configuration files are automatically detected by the application, so there is no need to restart the Docker container after making edits.

To add a new service, you can edit the `services.yaml` file and add a new entry under one of the service groups.

## Secret Management

Secret management is handled via [1Password CLI](https://developer.1password.com/docs/cli).
- **`services.yaml.tpl`**: This template file uses 1Password references (e.g., `op://...`) for secrets like API keys and passwords.
- **Workflow**: Before starting the container, secrets are unpacked and injected into `homepage/services.yaml` by running the `/home/shahvirb/gitsource/utils/op-unpack.sh` script.
  **Important:** The generated `homepage/services.yaml` file should *not* be committed to version control as it contains sensitive information. Only the `services.yaml.tpl` file should be versioned.

## Customization

You can further customize the appearance and functionality of your dashboard by adding your own CSS and JavaScript:

- `custom.css`: Add your custom CSS rules to this file to override the default styles.
- `custom.js`: Add your custom JavaScript to this file for more advanced customizations.
